Welcome to my new blog! This is my first post powered by Astro.

## Why Astro?

Astro is a modern static site generator that ships zero JavaScript by default. It's perfect for blogs and documentation sites.

### Key Features

- **Island Architecture**: Ship only the JavaScript you need
- **Content Collections**: Organize your content with type safety
- **Multiple Frameworks**: Mix React, Vue, Svelte components in one project

Check out the [Astro documentation](https://docs.astro.build) to learn more.
